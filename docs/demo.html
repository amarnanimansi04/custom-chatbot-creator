Custom Chatbot Creator

This is a live demo of an AI chatbot trained on a real website using Retrieval-Augmented Generation (RAG).

The chatbot in the bottom-right corner was built by:

  1. Crawling a website with Playwright (JS-rendered pages supported)
  2. Chunking the text and embedding it with all-MiniLM-L6-v2
  3. Storing vectors in ChromaDB (cosine similarity search)
  4. Answering questions with Groq LLaMA 3.1 using the top matching chunks

Click the chat bubble → ask anything about the website it was trained on.
